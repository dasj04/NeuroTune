# NeuroTune — BCI-Controlled Music System Using EEG Signals

**230103002 – Jyotirmoy Das | 230103032 – Gyan Ankur Das**  
Department of Information Technology, Gauhati University

A Brain-Computer Interface (BCI) system that classifies mental states from EEG signals in real time and adapts music playback accordingly — calm binaural beats when relaxed, energetic beats when active.

---

## How It Works

```
EEG Headset (or DEAP dataset)
        │
        ▼
  Raw EEG Signal
        │
  Butterworth Bandpass Filter
        │
        ├──► Alpha band (8–13 Hz)  ──┐
        └──► Beta  band (13–30 Hz) ──┤
                                     │
                            Band Power (FFT)
                                     │
                    ┌────────────────┴────────────────┐
                    │                                  │
              RBF-SVM Classifier              Alpha/Beta Ratio Rule
              (trained on DEAP)               (ratio > 1 → relaxed)
                    │                                  │
                    └──────────── Consensus ───────────┘
                                     │
                         Majority-Vote Smoother (3 windows)
                                     │
                    ┌────────────────┴─────────────────┐
                    │                                   │
              RELAXED state                       ACTIVE state
              → Calm Music (10 Hz)                → Energetic Music (18 Hz)
```

### Signal Processing Pipeline

| Step | Technique | Purpose |
|------|-----------|---------|
| Filtering | Butterworth Bandpass Filter | Isolate alpha (8–13 Hz) and beta (13–30 Hz) |
| Feature Extraction | FFT → Mean Band Power | Quantify frequency-domain activity |
| Classification | RBF-SVM + Alpha/Beta ratio rule | Determine RELAXED vs ACTIVE state |
| Consensus | SVM and ratio agree → use result; disagree → ratio wins | Robust against single-class training data |
| Smoothing | Majority vote over last 3 windows | Prevent rapid music switching |

## Dataset

This project uses the **DEAP dataset** (Database for Emotion Analysis using Physiological Signals).

- 32-channel EEG, 128 Hz sampling rate
- 40 trials per subject, each 63 seconds
- First 3 seconds (384 samples) are a baseline and are removed
- **Arousal label** (labels column 1) is used: `< 5` → RELAXED, `≥ 5` → ACTIVE

Download the dataset from [www.eecs.qmul.ac.uk/mmv/datasets/deap](http://www.eecs.qmul.ac.uk/mmv/datasets/deap) and place subject files in `data/raw/deap/`.

To switch subjects, update the `FILE_PATH` global at the top of `src/step1_load_deap.py`:

```python
FILE_PATH = "data/raw/deap/s03.dat"   # ← change subject here
```

## Classification Logic (Step 6)

Step 6 uses a dual-rule approach to ensure robust classification even when training data is single-class:

| Rule | Logic |
|------|-------|
| **SVM** | RBF-kernel SVM trained on alpha power, beta power, and alpha/beta ratio |
| **Ratio rule** | `alpha/beta > 1` → RELAXED (alpha dominant); `alpha/beta < 1` → ACTIVE (beta dominant) |
| **Consensus** | If both agree → use that result. If they disagree → ratio rule wins |

This prevents misclassification when the SVM is trained on an imbalanced or single-class dataset.

## Using a Real EEG Headset

Replace the pre-loaded DEAP array in `step6_realtime_demo.py` with a live headset stream.

**NeuroSky MindWave:**
```bash
pip install mindwave-python
```
```python

headset = mindwave.Headset('/dev/tty.MindWave')
data = headset.raw_value   # one raw EEG sample
```

